流程节点设计器取人员

接口地址 /flow/design/user-search

请求方式 GET

请求参数

参数名称 参数说明 请求类型 是否必须 数据类型
filter 过滤关键字 query false string
pageNo 第n页 query false integer
pageSize 一页记录数 query false integer

响应参数

参数名称 参数说明 类型 schema
data 人员数据 array 应用范围Model
errorInfo 错误信息Model ErrorInfo ErrorInfo
message 兼容SpringMvc的默认错误消息格式 string  
success 请求是否成功 boolean  
total 总记录数 integer(int64) integer(int64)

schema属性说明

应用范围Model

参数名称 参数说明 类型
description 详细描述，用于html的title属性 string
id Id string
name 显示名称 string
phone 电话号码 string
recipient 邮箱地址 string

ErrorInfo

参数名称 参数说明 类型
message 错误消息 string

响应示例

{
    "data": [
