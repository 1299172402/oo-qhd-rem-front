取审批人回调

接口地址 /flow/audit/user-search

请求方式 POST

请求参数

参数名称 参数说明 请求类型 是否必须 数据类型 schema
fetchAssignCallBackRo fetchAssignCallBackRo body true FetchAssignCallBackRo FetchAssignCallBackRo

schema属性说明

FetchAssignCallBackRo

参数名称 参数说明 请求类型 是否必须 数据类型 schema
activityDefinitionId 节点定义Id body false string
auditUserSearchCallBackData 取流程审批人回调数据 body false string
businessKey 业务主键 body false string
customData 自定义数据 body false string
processDefinitionKey 流程定义Key body false string
processInstanceId 流程实例Id body false string
resources 指派资源集合 body false array Resource
startUserId 流程发起人Id body false string  

Resource

参数名称 参数说明 请求类型 是否必须 数据类型 schema
applyScope 适用范围 body false string
dataScope 数据范围 body false string
multiInstance 是否会签，业务系统一般不需要过多处理，在返回时原样返回即可 body false boolean
priority 优先级，业务系统一般不需要过多处理，在返回时原样返回即可 body false integer(int32)
resourceId 资源Id，一般就是组Id body false string
type 此值目前只有group一种（即组） body false string  

响应参数

参数名称 参数说明 类型 schema
errorInfo 错误信息 ErrorInfo ErrorInfo
message 兼容SpringMvc的默认错误消息格式 string
resources 返回的人 array Resource
success 是否成功 boolean  

schema属性说明

ErrorInfo

参数名称 参数说明 类型 schema
message 错误消息 string  

Resource

参数名称 参数说明 类型 schema
type 固定值返回user string
multiInstance 是否会签，从入参复制过来即可 boolean
phone 人员的电话 string
priority 优先级，从入参复制过来即可 integer(int32)
recipient 人员的邮件 string
resourceId 人的Id string
resourceName 人的姓名 string
