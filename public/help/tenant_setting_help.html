租户设置说明

基本信息

  • 租户id：表明租户身份，不可以修改。
  • baseUri：回调业务系统Api的基地址。
  • TOKEN：回调业务系统时需要添加到请求头Authorization中的Token值。
  • 待办任务地址：用于拼装门户待办列表的任务链接。

通知相关设置

模板按通知类型（短信、邮件、站内信）和通知用途（催办、待办、告知）共分为9个可配置模板。模板支持使用变量替换。支持的变量见附录。具体的请求体见门户的文档。
以业管系统的待办站内信为例配置如下：
  {
      "result": [
          {
              "create_time": "${createTime}",
              "important_level": "1",
              "module_name": "${processDefinitionName}",
              "sender": "${senderCode}",
              "title": "业务平台提醒您，您有一项待办任务【${businessName}】需要处理。",
              "url": "${auditUrl}"
          }
      ]
  }
完成设置后还需要在流程上设置好通知方式后才会进行通知。

附录

通知url和模板中可使用的变量。在使用变量时将变量名放入${}即可。
变量名 说明
systemCode 系统编辑，格式 bpmn-租户id
receiverCode 接收人 OA Code
receiverName 接收姓名
senderCode 发送人 OA Code
senderName 发送人姓名
createTime 任务创建时间，格式为yyyyMMddHHmmss
businessName 流程名称
auditUrl 门户待办url(移动端)
processDefinitionName 流程定义的名称
activityName 当前审批节点的名称
