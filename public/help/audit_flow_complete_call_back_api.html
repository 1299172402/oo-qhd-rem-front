流程正常完成回调Api说明

接口地址 /flow/{flowInstanceId}/call-back/complete

请求方式 POST

请求参数

参数名称 参数说明 请求类型 是否必须 数据类型 schema
flowInstanceId 流程实例Id path true string
processEndCallBackRo 回调数据 body true ProcessEndCallBackRo ProcessEndCallBackRo

schema属性说明

ProcessEndCallBackRo

参数名称 参数说明 请求类型 是否必须 数据类型 schema
businessKey 业务主键 body false string
callBackProcessClass 回调处理类，在流程上配置 body false string
processDefinitionId 流程定义Id body false string
processDefinitionKey 流程定义Key body false string
processDefinitionVersion 流程版本 body false integer(int32)  

响应参数

参数名称 参数说明 类型 schema
errorInfo 错误信息 ErrorInfo ErrorInfo
message 兼容SpringMvc的默认错误消息格式 string
success 请求是否成功 boolean

schema属性说明

ErrorInfo

参数名称 参数说明 类型 schema
message 错误消息 string  

请示例


POST /flow/1/call-back/complete {
   "businessKey": "1",
   "callBackProcessClass": "com.cnooc.test.CallbackHandler",
   "processDefinitionId": "1",
   "processDefinitionKey": "test_flow_key",
   processDefinitionVersion: 1
}

响应示例

{
    "success": true
}
