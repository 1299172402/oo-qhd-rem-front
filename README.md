# 框架更新内容

###
1. 登录界面修改为Tab页样式 分为集团内部用户登录（未对接）与外部用户登录。

7. 更新table表格和复杂table表格的固定表头表尾样式，增加标题栏组件（注意：更新到组件样例和“样式库目录.docx”，不会对现有代码有影响）
8. 补充更新其他页面面板布局（对团队无影响）
